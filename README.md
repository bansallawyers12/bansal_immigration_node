# Bansal Immigration

Next.js App Router shell for the Bansal Immigration website. Use Node.js 24 LTS and npm.

The current Laravel site is the reference for pages, wording, images, and public URLs. This repository starts from that shell. Only the home page is implemented.

## Development

```sh
npm ci
npm run dev
npm run lint
npm run typecheck
npm run build
```

Copy `.env.example` to `.env.local` for local configuration. Do not commit `.env.local`.
